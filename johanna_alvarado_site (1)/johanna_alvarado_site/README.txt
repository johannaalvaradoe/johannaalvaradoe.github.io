Cómo publicarlo gratis
Opción A — GitHub Pages
1. Cree un repositorio nuevo en GitHub.
2. Suba index.html a la raíz del repositorio.
3. Vaya a Settings > Pages.
4. En "Build and deployment", seleccione "Deploy from a branch".
5. Seleccione main / root y guarde.

Opción B — Netlify
1. Entre a Netlify.
2. Cree un sitio nuevo y arrastre la carpeta que contiene index.html.
